ЗАМЕР+ — ПРИЁМНИК WINDOWS / SKETCHUP 2026 (версия 1.5)

1. Распакуйте ZIP. При необходимости установите Node.js LTS. Запустите start.cmd. Код сопряжения показывается только на вашем ПК в окне приёмника и хранится в Documents\ZamerPlus\receiver-config.json — никому его не отправляйте.
2. На iPhone в Замер+ → Проекты → Передача на ПК сохраните домашний IP, код сопряжения и, для передачи вне дома, IP Tailscale компьютера.
3. Дома iPhone попробует обычную сеть Wi-Fi. Вне дома установите Tailscale на ПК и iPhone и войдите в одну частную сеть. Включите Tailscale на iPhone и выберите в Замер+ канал «Из любой сети · Tailscale». Режим «Домашний Wi-Fi» используйте только дома. Приёмник автоматически начинает слушать Tailscale-интерфейс, как только компьютер войдёт в эту сеть.
4. Для автоматической отправки требуется установленное на iPhone приложение Zamer+ LiDAR Bridge 1.5. Если открыта ваша рабочая модель, SketchUp не должен заменять её: скан остаётся в Documents\ZamerPlus\Inbox. Для ручной обработки используйте Extensions → Zamer+ — Импортировать входящий скан в новую модель.
5. Передача JSON/DAE вручную в интерфейсе Замер+ остаётся доступной даже при выключенном приёмнике или Tailscale.

Для работы вне дома не открывайте порт 8787 в роутере. Tailscale шифрует трафик частной сети; домашний HTTP внутри Wi-Fi отдельно не зашифрован. Запускайте приёмник в собственной доверенной домашней сети и разрешите брандмауэром TCP 8787 лишь в домашней подсети или через интерфейс Tailscale. Компьютер должен оставаться включённым и иметь интернет.

Приёмник сохраняет JSON в Documents\ZamerPlus\Inbox, готовые модели — в Documents\ZamerPlus\Models. Подтверждение получения на iPhone означает приём на ПК, не окончание импорта в SketchUp. Если приёмник переустановлен, сохраняйте receiver-config.json — иначе изменится код сопряжения.
