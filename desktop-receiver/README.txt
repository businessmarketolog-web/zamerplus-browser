ЗАМЕР+ / ПРИЁМНИК WINDOWS

ДОМА: Запустите start.cmd на компьютере, укажите домашний IP и секретный код в Замер+ на iPhone.
ВНЕ ДОМА: Установите Tailscale на ПК и iPhone, войдите в одну частную сеть и включите VPN на iPhone. Запустите start_remote.cmd (отдельно от домашнего start.cmd). Он принимает замеры только через Tailscale IP 100.x.x.x. Узнайте адрес через команду tailscale ip -4 в Windows и введите в отдельное поле Tailscale на странице «Проекты → Передача на ПК» в Замер+.

Домашний и удалённый экземпляры работают с одной очередью Documents\ZamerPlus\Inbox и одним секретным кодом Documents\ZamerPlus\receiver-config.json. Код не пересылайте посторонним. В SketchUp импортируйте очередь в новую отдельную модель, не в рабочий мебельный проект.

Для Tailscale добавьте в брандмауэр Windows входящее разрешение TCP/8787 только с удалённых адресов 100.64.0.0/10 на собственный Tailscale IP компьютера, для node.exe. Не открывайте этот порт в домашнем роутере, не используйте Funnel или общедоступные ссылки. HTTP внутри VPN зашифрован Tailscale.

Приёмник на удалённом IP работает только после входа в Tailscale на обоих устройствах. Код сопряжения должен совпадать. В Замер+ можно экспортировать JSON или DAE вручную независимо от интернета и VPN. Код iPhone LiDAR Bridge должен быть обновлён до версии 1.5 или новее.
