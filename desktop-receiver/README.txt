ЗАМЕР+ — ПРИЁМНИК WINDOWS / SKETCHUP 2026

1. Распакуйте весь ZIP в отдельную папку на ПК.
2. Запустите start.cmd. На ПК должен быть Node.js (он уже установлен на вашем компьютере Den).
3. Разрешите Node.js доступ только к ЧАСТНЫМ сетям в брандмауэре Windows. Не открывайте порт 8787 в роутере и не запускайте приёмник в публичном Wi-Fi.
4. В чёрном окне появятся «IP компьютера» и «Код сопряжения». В Замер+ на iPhone откройте «Проекты» и введите их в разделе «Передача на ПК», затем нажмите «Сохранить подключение».
5. Подключите ПК и iPhone к одной доверенной локальной сети. Используйте обновлённый «Замер+ LiDAR Bridge» версии 1.4 или новее, иначе автоматическая передача не поддерживается.
6. Нажмите «Передать автоматически → ПК» у комнаты или «Весь проект → ПК». iPhone должен показать подтверждение приёма.

ВАЖНО: подтверждение на iPhone означает приём файла на компьютер, а НЕ завершение импорта в SketchUp. Приёмник складывает JSON в Documents\ZamerPlus\Inbox. Плагин Zamer+ Importer 1.1 автоматически импортирует следующий файл ТОЛЬКО в чистую пустую модель SketchUp и сохранит новый .skp в Documents\ZamerPlus\Models. Если в SketchUp уже открыт ваш рабочий проект, скан безопасно ждёт в очереди. Для приёма в отдельную модель выберите Extensions → Zamer+ — Импортировать входящий скан в новую модель. Не допускается автоматическая замена существующей модели.

Два ручных варианта остаются в Замер+: «JSON вручную» и «DAE вручную». В SketchUp JSON можно открыть через Extensions → Zamer+ — Import LiDAR JSON. Весь проект экспортируется через «Проект JSON вручную».

Место хранения кода приёмника: Documents\ZamerPlus\receiver-config.json. Не пересылайте код посторонним. Передача внутри Wi-Fi сети осуществляется по HTTP, без сквозного шифрования. Используйте только собственную доверенную сеть, не запускайте в общественных сетях и не включайте переадресацию порта на роутере.

Если ПК не виден: проверьте, что start.cmd продолжает работать, iPhone и ПК в одной сети, нет изоляции клиентов Wi-Fi и брандмауэр разрешает Node.js в частной сети. Браузер на телефоне не обязан иметь прямой доступ к HTTP: данные отправляет нативный LiDAR Bridge.
