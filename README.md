# Замер+ LiDAR → SketchUp 2026

Веб-приложение: https://businessmarketolog-web.github.io/zamerplus-browser/

**Передача файлов только вручную.** Автоматическая отправка с iPhone на ПК, сетевой приёмник, подключение через Wi-Fi/Tailscale и очередь автоимпорта отключены. Веб-приложение не обращается к компьютеру и не требует сетевых разрешений или кода сопряжения.

## Передать скан вручную

1. На iPhone в Замер+ откройте проект и комнату. Нажмите **«JSON вручную»** для нативного импорта SketchUp либо **«DAE вручную»** для формата COLLADA. Для объединения комнат используйте кнопку **«Проект JSON вручную»**.
2. Сохраните файл через стандартное меню iOS и передайте его на компьютер любым удобным способом: «Файлы», облачное хранилище, AirDrop (при поддержке ПК), USB или почта.
3. В SketchUp 2026 выберите `Extensions → Zamer+ — Import LiDAR JSON` и вручную укажите переданный `.json`, либо `File → Import` и выберите формат `.dae`.

Установить [Zamer+ Importer 1.2 (ручной импорт)](ZamerPlusImporter.rbz): `Extensions → Extension Manager → Install Extension`, затем перезапустите SketchUp. Плагин не запускает сетевую службу, таймеры и автоматическую обработку очереди.

## Данные и геометрия

Исходный RoomPlan-скан хранится отдельно от ручных правок; доступны контроль геометрии, заметки/фотографии, история сканов и резервная копия проекта. Перед объединением независимых комнат задайте проверенные координаты по контрольным размерам — без них размещение в общем SketchUp-проекте условное. Данные браузера Safari не очищайте, пока не экспортировали резервную копию.

LiDAR Bridge используется исключительно для нативного сканирования RoomPlan. Полученные данные возвращаются в браузер на iPhone; отправки непосредственно на компьютер в ручной версии нет.
