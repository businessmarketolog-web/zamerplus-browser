# Замер+ LiDAR → SketchUp 2026

Веб-приложение: https://businessmarketolog-web.github.io/zamerplus-browser/

## Способы передачи

- **Автоматически → ПК**: Windows-приёмник + LiDAR Bridge 1.5. Выберите канал «Из любой сети · Tailscale» (ПК и iPhone в одной частной сети Tailscale) либо «Только домашний Wi-Fi», затем укажите соответствующий IP и прежний код сопряжения. Приём на ПК не равен завершённому импорту; если SketchUp занят, JSON остаётся в очереди.
- **JSON вручную**: отдельная комната или весь проект, включая правки и фотографии. В SketchUp: `Extensions → Zamer+ — Import LiDAR JSON`.
- **DAE вручную**: COLLADA для отдельной комнаты, Z-up, миллиметры, стены толщиной 1 мм. Фотографии и история в DAE не помещаются.

## Windows

Скачайте [приёмник](ZamerPlusReceiver_Windows.zip), распакуйте, запустите `start.cmd`. Компьютеру нужен Node.js. В консоли будут указаны IP и код. При первом запуске разрешите доступ Node.js **только в частных сетях** Windows. Не пробрасывайте порт 8787 в интернет. JSON поступает в `Документы/ZamerPlus/Inbox`, импортированные модели — в `Документы/ZamerPlus/Models`.

## SketchUp 2026

Установите [расширение Zamer+ Importer](ZamerPlusImporter.rbz) через `Extensions → Extension Manager → Install Extension` и перезапустите SketchUp. Расширение 1.1 автоматически забирает очередной скан **только если открыта пустая, не изменённая модель**, создаёт отдельный `.skp` и никогда не заменяет существующий файл. Если открыта мебельная модель, используйте пункт `Extensions → Zamer+ — Импортировать входящий скан в новую модель`; SketchUp предложит сохранить текущую работу. Для просмотра очереди есть отдельная команда.

## iPhone

Обновите установленный через SideStore `Zamer+ LiDAR Bridge` до версии 1.5 из [релиза IPA](https://github.com/businessmarketolog-web/zamerplus-browser/releases/tag/lidar-bridge-latest) после успешной сборки GitHub Actions. При обновлении может потребоваться повторная подпись SideStore, см. его обычный срок действия. В Замер+ на странице проектов укажите домашний IP, удалённый IP Tailscale (при наличии) и код приёмника, затем выберите канал отправки. В режиме Tailscale передача доступна из любой сети с интернетом при включённом Tailscale на iPhone и ПК; домашний IP используйте только в своей Wi-Fi-сети.

Автоотправка ограничена размером URL-данных: если модель с большим количеством фотографий не помещается, используйте ручной JSON. HTTP-трафик внутри Wi-Fi не зашифрован: включайте приёмник только в собственной доверенной локальной сети.

## Передача вне дома через Tailscale (VPN)

Установите [Tailscale](https://tailscale.com/download) на Windows и iPhone и войдите **в одну и ту же частную сеть Tailscale**. Включите VPN в приложении Tailscale на iPhone. После авторизации на ПК получите адрес вида `100.x.x.x` через `tailscale ip -4`. В разделе «Проекты → Передача на ПК» Замер+ введите его во второе поле «IP ПК в Tailscale», а домашний IP оставьте в первом поле. Код приёмника одинаковый в обоих режимах. На улице приложение сначала попробует Tailscale, а дома при недоступном VPN переключится на домашний Wi-Fi. Прямая отправка не требует проброса портов домашнего роутера.

Для Windows запустите второй экземпляр приёмника с переменной окружения `ZAMER_BIND_IP=<IP из tailscale ip -4>`; домашний экземпляр продолжает работать на домашнем IP. Брандмауэр должен разрешать `TCP 8787` **только** от Tailscale-сети `100.64.0.0/10` на соответствующий локальный Tailscale IP. Вход на роутере и Tailscale Funnel **не включайте**. Приёмник проверяет секретный код на каждой отправке и сохраняет JSON в ту же локальную очередь `Documents/ZamerPlus/Inbox`. Передача по Tailscale шифруется внутри VPN; HTTP-сервис не публикуется в интернет.

До входа в Tailscale на **обоих** устройствах удалённая отправка работать не будет. Весь путь iPhone → Tailscale → Windows → SketchUp проверяется отдельно после авторизации. Кнопки ручной передачи JSON/DAE остаются доступны без VPN.

## Данные и изменения

Каждая комната сохраняет исходный RoomPlan-скан отдельно от ручных корректировок. История включает до пяти предыдущих состояний; восстановление не перезаписывает исходный скан без подтверждения. Фотографии/заметки привязываются к стене, проёму или комнате; в SketchUp заметки отображаются как подписи, фотографии — на скрытом по умолчанию теге `Zamer+ Photos`. Файлы фотографий хранятся локально в `Документы/ZamerPlus/Assets`.

Сканы комнат независимо получены с LiDAR и **не имеют гарантированной взаимной привязки**. Для точной сборки объекта задайте X/Y/поворот в «Разместить комнаты» по контрольным замерам. Без подтверждения координат комнаты размещаются рядом условно, а проект помечается как неподтверждённый. Контроль качества показывает внутренние геометрические несоответствия, но не заменяет лазерный контрольный замер.

Резервная копия из приложения сохраняет все проекты и их версии. Не очищайте данные Safari до сохранения резервной копии.


## Отправка вне дома (iOS Bridge 1.5)

Установите Tailscale на Windows и iPhone, войдите в **одну частную сеть Tailscale** и включите соединение на обоих устройствах. На компьютере получите его приватный IP командой `tailscale ip -4`; обычно он находится в диапазоне `100.64.0.0/10`. На iPhone откройте Замер+ → Проекты → Передача на ПК, укажите IP Tailscale в отдельном поле и выберите **«Из любой сети · Tailscale»**. Сохраните прежний код сопряжения; новую учётную запись Замер+ создавать не нужно.

При отправке через Tailscale приложение обращается **только** к приватному Tailscale-IP и не отправляет сканы на похожие локальные адреса чужой Wi-Fi-сети. Режим домашнего Wi-Fi можно включить вручную; его используйте только дома. Между устройствами трафик Tailscale зашифрован, но домашний HTTP работает отдельно внутри вашей доверенной сети. Не открывайте TCP 8787 на роутере.

Компьютер и приёмник должны быть включены. После принятия скана на ПК он появится в очереди; импорт в SketchUp выполняется отдельно, если у вас открыт рабочий проект. Ручной JSON/DAE остаётся доступен без VPN. Большие сканы с множеством фотографий могут превысить лимит передачи через ссылку iOS Bridge — для них используйте ручной JSON.
