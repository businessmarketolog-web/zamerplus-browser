Подключение

Bosch через Safari

1. Установите и включите WebBLE Safari extension. 2. Разрешите расширению доступ к этому сайту. 3. Включите Bluetooth на GLM. 4. Нажмите «Подключить Bosch».

LiDAR через Safari

Прямого Web API для RoomPlan/LiDAR в Safari нет. Поэтому сайт уже поддерживает bridge‑события zamerplus:lidar:start / zamerplus:lidar:result. Их должен обслуживать нативный Safari‑helper.
